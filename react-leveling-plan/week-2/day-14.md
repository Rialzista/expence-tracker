# День 14 — Практика: CRUD-приложение

**Неделя:** 2 — State management и работа с данными
**Цель дня:** собрать неделю в цельный проект — полноценное CRUD-приложение с реальным API.

## Задача дня
Собрать приложение (например, тот же список задач, но уже с реальным бэкендом — можно использовать API из `dotnet-core-plan`, если он уже готов, или любой публичный mock-API):
- Zustand или Redux Toolkit для клиентского state (UI-фильтры, тема и т.д.)
- TanStack Query для всех серверных данных (список, создание, редактирование, удаление)
- React Router v6+ с вложенными роутами и защищённым роутом
- Полная типизация без `any`

## Чек-лист
- [ ] Чёткое разделение: клиентский state — в Zustand/RTK, серверный — в TanStack Query (не смешаны)
- [ ] Хотя бы одна optimistic update операция
- [ ] Роутинг с защищённым роутом работает
- [ ] Нет ручных `useEffect + fetch` — всё через `useQuery`/`useMutation`
