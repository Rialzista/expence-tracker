# День 9 — Zustand

**Неделя:** 2 — State management и работа с данными
**Цель дня:** освоить лёгкий современный state-менеджер — сейчас один из самых востребованных вариантов в вакансиях наравне с Redux Toolkit.

## Темы
- Создание store через `create()`, без Provider-обёрток (в отличие от Context/Redux)
- Селекторы — подписка компонента только на нужный кусок state (решает проблему лишних ре-рендеров из дня 8)
- Actions прямо в store, асинхронные actions
- Middleware: `persist` (синхронизация с localStorage), `devtools`

## Практика
- [ ] Создать Zustand-store для приложения из недели 1 (список задач) — вынести state и actions из компонента в store
- [ ] Использовать селекторы в компонентах, убедиться через Profiler, что компонент ре-рендерится только при изменении нужного кусочка state
- [ ] Подключить `persist` middleware — состояние переживает перезагрузку страницы
- [ ] Подключить `devtools` middleware, посмотреть на историю изменений в Redux DevTools

## Что должно получиться к концу дня
Приложение из недели 1 переведено на Zustand, с корректными селекторами и persist.
