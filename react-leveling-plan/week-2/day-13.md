# День 13 — React Router v6+

**Неделя:** 2 — State management и работа с данными
**Цель дня:** освоить актуальную версию роутинга — API сильно поменялся начиная с v6, если раньше видели v5 или ниже.

## Темы
- `createBrowserRouter` + data router API (loaders, actions) — новый подход вместо простого `<Routes>`/`<Route>` без loaders
- Вложенные роуты и `<Outlet />` — концептуально похоже на Angular's child routes + `<router-outlet>`
- `useNavigate`, `useParams`, `useSearchParams`
- Защищённые роуты (auth guard) — аналог `CanActivate` в Angular, но реализуется вручную через обёртку-компонент

## Практика
- [ ] Настроить роутинг для приложения через `createBrowserRouter` с вложенными роутами и layout-компонентом с `<Outlet />`
- [ ] Использовать `loader` для предзагрузки данных страницы (сравнить с Angular Resolver)
- [ ] Реализовать защищённый роут (редирект на логин, если нет токена)
- [ ] Использовать `useSearchParams` для сохранения фильтров списка в URL

## Что должно получиться к концу дня
Полноценный роутинг с вложенными маршрутами, защитой роутов и синхронизацией фильтров с URL.
