# День 4 — useRef, forwardRef, useImperativeHandle

**Неделя:** 1 — Хуки на новом уровне, TypeScript, тулинг
**Цель дня:** освоить работу с DOM-элементами и мутируемым состоянием, не вызывающим ре-рендер.

## Темы
- `useRef` для доступа к DOM-элементу и для хранения значения между рендерами без ре-рендера (в отличие от `useState`)
- `forwardRef` — проброс ref через кастомный компонент к внутреннему DOM-элементу
- `useImperativeHandle` — императивный API компонента (кастомизация того, что "видно" через ref) — использовать редко, но нужно понимать
- Когда `useRef` уместен, а когда стоит остаться на декларативном подходе через state

## Практика
- [ ] Реализовать фокус на input по клику кнопки через `useRef`
- [ ] Использовать `useRef` для хранения значения между рендерами (например, предыдущее значение пропса), без лишнего ре-рендера
- [ ] Обернуть кастомный Input-компонент в `forwardRef`, прокинуть ref снаружи до нативного `<input>`
- [ ] Опционально: `useImperativeHandle` — открыть наружу только метод `focus()`, скрыв остальной DOM-элемент
