# День 5 — Кастомные хуки

**Неделя:** 1 — Хуки на новом уровне, TypeScript, тулинг
**Цель дня:** освоить главный механизм переиспользования логики в React — концептуальный аналог сервисов в Angular, но с другим механизмом связывания с компонентом.

## Темы
- Правила хуков (вызывать только на верхнем уровне, только из компонентов/других хуков) и почему они существуют (порядок вызовов важен для внутренней реализации React)
- Экстракция повторяющейся логики (например, работа с localStorage, debounce, отслеживание размера окна) в кастомный хук `useXxx`
- Разница с Angular-сервисами: кастомный хук — это не синглтон, а переиспользуемая логика, которая создаёт **новый** независимый стейт при каждом вызове в каждом компоненте

## Практика
- [ ] Написать `useLocalStorage(key, initialValue)` — синхронизация state с localStorage
- [ ] Написать `useDebounce(value, delay)` — для debounce поискового ввода
- [ ] Написать `useWindowSize()` — отслеживание размеров окна с cleanup на resize-listener
- [ ] Использовать хотя бы 2 из них в реальном маленьком компоненте (например, debounced-поиск с сохранением последнего запроса в localStorage)

## Что должно получиться к концу дня
Уверенное написание кастомных хуков как основного инструмента переиспользования логики.
