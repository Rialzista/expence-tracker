# День 6 — TypeScript с React

**Неделя:** 1 — Хуки на новом уровне, TypeScript, тулинг
**Цель дня:** закрыть React-специфичные паттерны типизации — сам TypeScript вы уже знаете глубоко через Angular, тут только "прикладная" часть.

## Темы
- Типизация props: `interface Props { ... }` vs `type Props = { ... }`, дженерики в props
- Типизация событий (`React.ChangeEvent<HTMLInputElement>`, `React.MouseEvent<HTMLButtonElement>`)
- Типизация хуков: `useState<T>`, типизация кастомных хуков с дженериками
- `children` типизация (`React.ReactNode` vs `React.ReactElement`)
- `FC<Props>` vs обычное объявление функции с типизированными props — почему сообщество в основном отошло от `FC`

## Практика
- [ ] Типизировать компонент с дженериком в props (например, универсальный `List<T>`, принимающий `items: T[]` и `renderItem: (item: T) => ReactNode`)
- [ ] Типизировать обработчики событий формы (change, submit) без `any`
- [ ] Типизировать кастомный хук из дня 5 с дженериком (`useLocalStorage<T>`)
- [ ] Типизировать компонент, принимающий `children`

## Что должно получиться к концу дня
Уверенная типизация любого React-компонента и хука без единого `any`.
