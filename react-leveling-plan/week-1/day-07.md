# День 7 — Практика/повторение недели 1

**Неделя:** 1 — Хуки на новом уровне, TypeScript, тулинг
**Цель дня:** собрать все хуки и типизацию недели в одну цельную задачу.

## Задача дня
Написать небольшое приложение "список задач с фильтрацией и поиском" (без бэкенда, in-memory), используя всё из недели:
- Строго типизированные props и state (никакого `any`)
- `useState` + функциональные обновления там, где нужно
- `useEffect` с корректными зависимостями и cleanup (например, debounce поиска)
- `useMemo` для отфильтрованного списка (осознанно, с пониманием зачем)
- Минимум один кастомный хук (например, `useDebounce` из дня 5)
- `useRef` хотя бы в одном месте (например, автофокус на input добавления задачи)

## Чек-лист
- [ ] Приложение полностью типизировано
- [ ] Нет лишних ре-рендеров (проверено через React DevTools Profiler)
- [ ] Хотя бы один кастомный хук переиспользован
- [ ] Код не содержит `useEffect` с пустым или неверным массивом зависимостей "чтобы просто работало"
