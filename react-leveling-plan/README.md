# План прокачки React — 3-4 недели

Контекст: большой опыт Angular, React был раньше, но давно и не в фокусе. Задача — не изучать React с нуля, а закрыть разрыв в современной экосистеме (хуки на новом уровне, актуальный state management, Next.js, тестирование) до уровня, закрывающего Middle+ вакансии.

Формат: 28 дней, по одному md-файлу на день, внутри — задачи с чекбоксами. Базовые вещи (JSX, что такое компонент, props) сознательно не расписаны отдельно — вы это знаете, план бьёт сразу в то, что изменилось или было незнакомо.
