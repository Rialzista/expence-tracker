# День 15 — React Hook Form

**Неделя:** 3 — Формы и Next.js
**Цель дня:** освоить стандарт де-факто для форм в React — концептуально должно лечь легко благодаря опыту Angular Reactive Forms.

## Темы
- `useForm`, `register`, `handleSubmit` — минимум ре-рендеров за счёт неконтролируемых полей (в отличие от полностью controlled-подхода через `useState` на каждое поле)
- Сравнение с Angular Reactive Forms: `FormGroup`/`FormControl` ↔ `useForm`/`register`, `formGroup.valid` ↔ `formState.isValid`
- Controlled-компоненты внутри RHF через `Controller` (для сторонних UI-библиотек, не поддерживающих `register` напрямую)
- Работа с массивами полей: `useFieldArray`

## Практика
- [ ] Собрать форму (например, форма задачи с несколькими полями) через `useForm` + `register`
- [ ] Обернуть сторонний/кастомный компонент (например, кастомный select) через `Controller`
- [ ] Реализовать динамический список полей через `useFieldArray` (например, список тегов)
- [ ] Сравнить с тем, как та же форма выглядела бы через `useState` на каждое поле — прочувствовать разницу в кол-ве ре-рендеров

## Что должно получиться к концу дня
Уверенное владение RHF для форм любой сложности, включая динамические поля.
