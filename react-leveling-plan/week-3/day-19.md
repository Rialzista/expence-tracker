# День 19 — Данные в Next.js: Server Components и Server Actions

**Неделя:** 3 — Формы и Next.js
**Цель дня:** освоить получение и изменение данных по-новому — без отдельного API-роута для каждого действия.

## Темы
- Fetch данных прямо в Server Component (`await fetch(...)` или прямой вызов функции работы с БД) — как это меняет подход по сравнению с TanStack Query (день 11), и когда TanStack Query всё ещё нужен (для клиентских, часто обновляемых данных)
- Server Actions (`'use server'`) — функции-мутации, вызываемые прямо из формы/клиента без ручного создания API-роута
- `revalidatePath`/`revalidateTag` — инвалидация кэша после мутации

## Практика
- [ ] Получить список данных прямо в Server Component через `await`, без useEffect/useQuery
- [ ] Реализовать Server Action для создания записи, вызвать его прямо из `<form action={...}>`
- [ ] Добавить `revalidatePath` после успешной мутации, чтобы список на странице обновился

## Что должно получиться к концу дня
Понимание, когда данные тянуть на сервере (Server Component), а когда — на клиенте (TanStack Query из недели 2), и как их мутировать через Server Actions.
