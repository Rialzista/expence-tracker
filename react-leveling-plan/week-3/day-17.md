# День 17 — Next.js: App Router

**Неделя:** 3 — Формы и Next.js
**Цель дня:** начать осваивать Next.js — фреймворк, который сейчас фактически стандарт для серьёзных React-проектов (файловый роутинг, SSR из коробки).

## Темы
- File-based routing: структура `app/`, `page.tsx`, `layout.tsx`, вложенные layouts
- Сравнение с React Router (день 13): роутинг определяется структурой файлов, а не конфигом
- Динамические сегменты (`app/tasks/[id]/page.tsx`), route groups
- `loading.tsx`, `error.tsx` — встроенные состояния загрузки/ошибки на уровне роута

## Практика
- [ ] Создать Next.js проект: `npx create-next-app@latest`
- [ ] Настроить пару вложенных роутов с общим `layout.tsx`
- [ ] Добавить динамический роут (`[id]`) и получить параметр
- [ ] Добавить `loading.tsx` и `error.tsx` для одного из роутов, посмотреть как они подхватываются автоматически

## Что должно получиться к концу дня
Рабочий Next.js-проект с файловым роутингом, вложенными layouts и динамическими сегментами.
