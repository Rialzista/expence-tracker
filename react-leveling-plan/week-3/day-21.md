# День 21 — Практика: страница на Next.js App Router

**Неделя:** 3 — Формы и Next.js
**Цель дня:** собрать неделю в цельный результат — полноценная фича на Next.js, готовая стать частью капстоуна.

## Задача дня
Реализовать раздел приложения (например, "Задачи") полностью на Next.js App Router:
- Список задач — Server Component, данные получены на сервере, стратегия рендеринга выбрана осознанно (ISR или SSR)
- Форма создания задачи — Client Component с React Hook Form + Zod (недели 15-16), отправка через Server Action
- Динамическая страница деталей задачи (`[id]/page.tsx`)
- Разделение на Server/Client Components обосновано, а не случайно

## Чек-лист
- [ ] Список рендерится на сервере без лишнего JS на клиенте для статичной части
- [ ] Форма валидируется через Zod, отправляется через Server Action
- [ ] После создания задачи список обновляется (`revalidatePath`) без ручного рефреша
- [ ] Динамическая страница деталей корректно получает параметр из URL

## Итог недели
Зафиксируйте: где граница Server/Client Components ощущалась естественной, а где — раздражающим ограничением по сравнению с "обычным" React/Angular, где такого разделения нет.
