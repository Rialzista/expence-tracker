# День 23 — Тесты хуков/компонентов, мок API через MSW

**Неделя:** 4 — Тестирование, производительность, капстоун
**Цель дня:** научиться тестировать более сложные сценарии — кастомные хуки и компоненты, зависящие от сети.

## Темы
- `renderHook` из RTL — тестирование кастомных хуков в изоляции
- MSW (Mock Service Worker) — перехват сетевых запросов на уровне сети, а не мокирование конкретных функций (реалистичнее и меньше связано с реализацией)
- Тестирование компонентов с TanStack Query (обёртка в `QueryClientProvider` в тестах)
- Тестирование форм: заполнение полей через `userEvent`, проверка ошибок валидации

## Практика
- [ ] Написать тест на кастомный хук из недели 1 (например, `useDebounce`) через `renderHook`

- [ ] Написать тест на компонент, использующий `useQuery` — проверить loading state и итоговые данные, используя MSW-мок вместо реального запроса
- [ ] Написать тест на форму (день 15-16): невалидный ввод → ошибка отображается; валидный ввод → сабмит вызывается
