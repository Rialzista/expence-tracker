# День 22 — Тестирование: React Testing Library + Vitest

**Неделя:** 4 — Тестирование, производительность, капстоун
**Цель дня:** освоить философию и инструменты тестирования, актуальные для React-проектов сейчас.

## Темы
- Философия React Testing Library: тестировать поведение, видимое пользователю (что отрендерилось, что произошло по клику), а не внутреннюю реализацию компонента
- Vitest как современная замена Jest (быстрее, нативно работает с Vite) — API почти идентичен Jest
- `render`, `screen`, запросы (`getByRole`, `getByText`) — приоритет `getByRole` как наиболее устойчивого к рефакторингу
- `userEvent` vs `fireEvent` — почему `userEvent` предпочтительнее (эмулирует реальное поведение пользователя точнее)

## Практика
- [ ] Настроить Vitest + React Testing Library в проекте
- [ ] Написать тест на простой компонент: рендер, проверка текста через `getByRole`/`getByText`
- [ ] Написать тест с `userEvent` — клик по кнопке меняет отображаемое состояние
- [ ] Осознанно избегать тестирования деталей реализации (например, не проверять внутренний state компонента напрямую)

Понимание философии RTL и рабочая настройка тестового окружения.
