# День 25 — Стилизация (Tailwind) и доступность

**Неделя:** 4 — Тестирование, производительность, капстоун
**Цель дня:** закрыть современный подход к стилизации (самый частый запрос в вакансиях сейчас) и базовую доступность.

## Темы
- Tailwind CSS — utility-first подход, почему он стал стандартом де-факто в новых React/Next.js проектах
- Конфигурация темы, работа с `dark:` вариантами, responsive-префиксами
- Базовая доступность: семантические теги, `aria-*` атрибуты, доступность через клавиатуру (фокус, `tabIndex`), контраст
- Компонентные UI-библиотеки поверх Tailwind (shadcn/ui или аналог) — коротко, для контекста

## Практика
- [ ] Настроить Tailwind в проекте (если ещё не настроен через `create-next-app`)
- [ ] Переписать стили нескольких компонентов капстоуна на Tailwind-классы
- [ ] Добавить dark-mode переключение через `dark:`-варианты
- [ ] Пройтись по ключевым интерактивным элементам (кнопки, инпуты, модалки) и проверить доступность с клавиатуры + базовые `aria-*` атрибуты

## Что должно получиться к концу дня
Капстоун-проект стилизован через Tailwind, ключевые интерактивные элементы доступны с клавиатуры.
