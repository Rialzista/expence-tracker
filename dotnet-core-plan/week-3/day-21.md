# День 21 — Практика: переезд API на реальную БД

**Неделя:** 3 — Данные (EF Core)
**Цель дня:** собрать неделю в цельный результат — API готово к тому, чтобы стать бэкендом капстоун-проекта.

## Задача дня
Довести Todo/задача-API до полноценного состояния:
- Реальная БД через EF Core с миграциями
- Минимум одна связь между сущностями (например, Task ↔ Category)
- Все эндпоинты работают через DTO, не через Entity напрямую
- Валидация входных данных с понятными ошибками
- Пагинация и фильтрация хотя бы на одном GET-эндпоинте

## Чек-лист
- [ ] `dotnet ef database update` применяет миграции без ошибок на чистой БД
- [ ] Все эндпоинты используют DTO
- [ ] Невалидный запрос возвращает понятную 400-ошибку
- [ ] Есть хотя бы один эндпоинт со связью (`Include`) и один с пагинацией

## Итог недели
Зафиксируйте: этот backend уже полностью готов быть API для фронтенда — на следующей неделе именно его вы будете защищать JWT и подключать к Angular/React.
