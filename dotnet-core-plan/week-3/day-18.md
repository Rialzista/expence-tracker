# День 18 — LINQ-запросы с EF Core

**Неделя:** 3 — Данные (EF Core)
**Цель дня:** научиться писать более сложные запросы средствами LINQ поверх EF Core.

## Темы
- Фильтрация (`Where`), сортировка (`OrderBy`), пагинация (`Skip`/`Take`)
- Связи между таблицами (one-to-many) и `Include`/`ThenInclude` для загрузки связанных данных
- Проекции через `Select` — загружать только нужные поля вместо всей сущности
- Разница между IQueryable (ещё не выполнено) и IEnumerable (уже в памяти) — важный нюанс производительности

## Практика
- [ ] Добавить вторую связанную сущность (например, `Category` для задач, one-to-many)
- [ ] Написать эндпоинт со связью через `Include`
- [ ] Добавить пагинацию (`Skip`/`Take`) и фильтрацию по параметру запроса
- [ ] Сделать projection-запрос через `Select` на DTO вместо полной сущности

## Что должно получиться к концу дня
Уверенное написание фильтрованных, отсортированных, пагинированных запросов со связями.
