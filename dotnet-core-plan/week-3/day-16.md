# День 16 — Миграции

**Неделя:** 3 — Данные (EF Core)
**Цель дня:** освоить Code First подход через миграции — замена ручных SQL-скриптов или EDMX-дизайнера.

## Темы
- `dotnet ef migrations add <Name>` — что генерируется и почему это нужно коммитить в git
- `dotnet ef database update` — применение миграций
- Откат миграции, удаление последней миграции
- `dotnet-ef` как отдельный global tool (`dotnet tool install --global dotnet-ef`)

## Практика
- [ ] Установить `dotnet-ef` как global tool
- [ ] Создать первую миграцию и применить её — увидеть созданную БД (файл SQLite)
- [ ] Добавить новое поле в модель, создать вторую миграцию, применить
- [ ] Откатить миграцию и понять, что происходит с данными при откате

## Что должно получиться к концу дня
Уверенное владение циклом "поменял модель → миграция → применил" без страха что-то сломать.
