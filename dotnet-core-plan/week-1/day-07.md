## Задача дня

- `record` для модели `TaskItem`
- nullable reference types включены
- pattern matching для обработки команд пользователя (add/list/done/exit)
- async-метод, имитирующий сохранение (например, `await Task.Delay(...)` + запись в файл через `File.WriteAllTextAsync`)
- top-level statements в `Program.cs`
