# День 1 — Установка окружения, dotnet CLI

**Неделя:** 1 — Язык и экосистема
**Цель дня:** поднять рабочее окружение и понять базовый workflow через CLI (без Visual Studio-мышки).

## Темы
- Установка .NET SDK (актуальная LTS — .NET 8)
- Выбор IDE: Rider или VS Code + C# Dev Kit
- `dotnet --version`, `dotnet --info` — проверка окружения
- Базовые команды: `dotnet new`, `dotnet run`, `dotnet build`

## Практика
- [ ] Установить .NET SDK, проверить `dotnet --info`
- [ ] Настроить IDE (расширения для C#, форматирование, отладка)
- [ ] Создать консольный проект: `dotnet new console -n HelloCore`
- [ ] Запустить его через `dotnet run` и через отладчик в IDE
- [ ] Понять структуру: `Program.cs`, `.csproj`, `bin/`, `obj/`

## Что должно получиться к концу дня
Рабочее окружение, консольный проект запускается и отлаживается без Visual Studio.
