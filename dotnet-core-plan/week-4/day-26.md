# День 26 — Капстоун: подключение frontend к API (часть 1)

**Неделя:** 4 — Auth, тесты, деплой, склейка с frontend
**Цель дня:** начать собирать финальный fullstack-проект — та часть, где ваш frontend-опыт (Angular/React/Vue) работает напрямую на результат.

## План
- Выбрать фреймворк для капстоуна (логичнее Angular — это то, что дальше идёт в резюме как "Angular + .NET fullstack")
- Поднять новый frontend-проект (или взять заготовку), настроить HttpClient/service-слой для похода к API
- Реализовать экран логина: форма → запрос к `/login` → сохранение JWT (localStorage/памяти) → редирект

## Практика
- [ ] Создать/подготовить frontend-проект
- [ ] Реализовать сервис для похода к API (базовый URL, обработка ошибок)
- [ ] Экран логина полностью работает: неверные данные — ошибка, верные — токен получен и сохранён
- [ ] Добавить interceptor/middleware на фронте, который прикладывает JWT к каждому запросу

## Что должно получиться к концу дня
Рабочий логин end-to-end: фронтенд получает JWT от .NET API и умеет прикладывать его к последующим запросам.
