# День 23 — Роли/claims, ASP.NET Core Identity

**Неделя:** 4 — Auth, тесты, деплой, склейка с frontend
**Цель дня:** довести аутентификацию до полноценной системы пользователей с реальной регистрацией и ролями.

## Темы
- Claims-based authorization: `[Authorize(Roles = "Admin")]`, кастомные claims
- ASP.NET Core Identity — что даёт из коробки (регистрация, хэширование паролей, управление пользователями) и когда это оправдано вместо самодельного JWT-логина
- Хранение пользователей в той же БД через EF Core (Identity интегрируется с DbContext)

## Практика
- [ ] Если решаете использовать Identity — подключить `AddIdentity`, настроить хранение в текущей БД
- [ ] Реализовать полноценную регистрацию пользователя (с хэшированием пароля — не руками, через Identity)
- [ ] Добавить роли (например, "User"/"Admin") и защитить один эндпоинт по роли
- [ ] Если Identity избыточен для проекта — как минимум добавить кастомные claims в JWT (userId, роль) и проверить их в `[Authorize]`

## Что должно получиться к концу дня
Полноценная система логина/регистрации с ролями, готовая к реальному использованию с фронтендом.
