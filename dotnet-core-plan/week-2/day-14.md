# День 14 — Практика: CRUD API на in-memory данных

**Неделя:** 2 — ASP.NET Core фундамент
**Цель дня:** собрать всё пройденное за неделю в один цельный проект — без БД, но со всей инфраструктурой.

## Задача дня
Собрать Todo API "с нуля", применяя всё, что прошли на неделе:
- Полный CRUD (GET all, GET by id, POST, PUT, DELETE) — на выбор: Controllers или Minimal API
- DI для сервиса, хранящего данные (in-memory, Singleton или Scoped — обосновать выбор)
- Кастомный middleware для логирования запросов и глобальной обработки ошибок
- Конфигурация через `appsettings.json` + `IOptions<T>` хотя бы для одного параметра
- Swagger UI работает и показывает все эндпоинты

## Чек-лист
- [ ] Все CRUD-операции работают и протестированы через Swagger
- [ ] DI используется осознанно (не всё в Singleton "на всякий случай")
- [ ] Middleware логирует запросы и ловит ошибки
- [ ] Проект собирается без warnings
