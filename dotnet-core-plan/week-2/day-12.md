# День 12 — Controllers vs Minimal APIs

**Неделя:** 2 — ASP.NET Core фундамент
**Цель дня:** освоить классический контроллерный подход (ближе к старому Web API по ощущениям) и понять, когда что выбирать.

## Темы
- `[ApiController]`, `ControllerBase`, атрибутная маршрутизация (`[HttpGet]`, `[Route]`)
- Автоматическая валидация модели через `[ApiController]`
- Model binding в контроллерах — что изменилось по сравнению со старым Web API
- Когда выбирать Controllers (крупные API, много эндпоинтов, нужна общая инфраструктура) vs Minimal APIs (микросервисы, простые CRUD)
