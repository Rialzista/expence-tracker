# День 11 — Minimal APIs

**Неделя:** 2 — ASP.NET Core фундамент
**Цель дня:** освоить лёгкий подход к API без контроллеров — стандарт для небольших сервисов в новых проектах.

## Темы
- `app.MapGet`, `app.MapPost`, `app.MapPut`, `app.MapDelete`
- Привязка параметров: из route, query, body (`[FromBody]`, `[FromQuery]`, автоматический binding)
- Возврат результатов: `Results.Ok()`, `Results.NotFound()`, `Results.Created()`
- Группировка эндпоинтов через `MapGroup`

## Практика
- [ ] Создать проект с Minimal API: пара GET/POST эндпоинтов на in-memory списке объектов
- [ ] Настроить привязку тела запроса (`[FromBody]`) для POST
- [ ] Вернуть разные коды ответа в зависимости от результата (200/201/404)
- [ ] Сгруппировать эндпоинты через `MapGroup("/api/items")`

## Что должно получиться к концу дня
Рабочий набор эндпоинтов на Minimal API без единого контроллера.
