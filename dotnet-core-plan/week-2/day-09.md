# День 9 — Свой middleware

**Неделя:** 2 — ASP.NET Core фундамент
**Цель дня:** написать полноценный кастомный middleware как класс — то, что раньше делалось через `HttpModule`.

## Темы
- Middleware как класс: конструктор с `RequestDelegate next`, метод `InvokeAsync(HttpContext context)`
- Extension-метод `UseMyMiddleware()` для регистрации
- Типовые кейсы: логирование запросов, обработка ошибок (exception handling middleware), замер времени выполнения

## Практика
- [ ] Написать class-based middleware для логирования каждого запроса (метод, путь, статус-код, время выполнения)
- [ ] Написать exception-handling middleware, который ловит необработанные исключения и возвращает единый JSON с ошибкой
- [ ] Зарегистрировать оба в правильном порядке в `Program.cs`

## Что должно получиться к концу дня
Свой middleware для логирования и глобальной обработки ошибок, работающий на любом эндпоинте.
